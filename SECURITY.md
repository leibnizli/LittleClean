# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest release on [GitHub Releases](https://github.com/leibnizli/LittleClean/releases) | Yes |
| Older releases | No |

Please update to the latest release before reporting an issue.

## Reporting a Vulnerability

If you discover a security vulnerability in LittleClean, please report it privately.

**Preferred contact:** stormte@gmail.com

Please include:

- A description of the issue
- Steps to reproduce (if possible)
- Affected version / build
- Potential impact

Please do **not** open a public GitHub issue for security-sensitive reports.

I will try to acknowledge reports within a few days and follow up after assessing the issue. If a fix is needed, it will typically ship in a new release.
